# PropVerse

A visual-first asset discovery library for AI filmmaking.

PropVerse helps creators find the exact objects they imagine, even when they do not know the object's name. Browse visual references, open an item, and use its image and generated description as context for AI image or video generation.

## MVP scope

- Home page
- Visual Components library
- Broad object categories in the left sidebar
- Detailed object cards in the main content area
- Item detail view with visual reference and copyable prompt

This first demo is intentionally a discovery library, not a scene editor or 3D modeling tool.

## Development

```bash
npm install
npm run dev
```
